# Smart Parking IoT System 🚗🅿️

ระบบจัดการลานจอดรถอัจฉริยะด้วยเทคโนโลยี IoT ที่ช่วยเพิ่มความสะดวกและแม่นยำในการควบคุมการเข้า-ออก และตรวจสอบพื้นที่ว่างภายในลานจอดรถ

---

## 📌 ภาพรวมโปรเจกต์ (Project Overview)
โปรเจกต์นี้พัฒนาขึ้นเพื่อแก้ปัญหาการจัดการลานจอดรถ โดยใช้ไมโครคอนโทรลเลอร์ **ESP32** เป็นหน่วยประมวลผลหลัก ร่วมกับเซนเซอร์ต่างๆ เพื่อตรวจจับยานพาหนะและควบคุมสิทธิ์การเข้าใช้งานผ่านบัตร RFID ระบบจะทำงานประสานกับ Web Server เพื่อบันทึกข้อมูลและแสดงสถานะการจอดแบบเรียลไทม์

---

## 🛠️ อุปกรณ์ที่ใช้ (Hardware Components)
* **ESP32:** หน่วยประมวลผลหลัก (Microcontroller)
* **RFID Reader:** สำหรับสแกนบัตรยืนยันตัวตนเพื่อเข้าลานจอด
* **Ultrasonic Sensor (HC-SR04):** สำหรับตรวจจับระยะวัตถุ (ตรวจสอบพื้นที่ว่าง/มีรถจอด)
* **LDR Sensor:** สำหรับตรวจจับแสงสว่าง (เปิด-ปิดไฟอัตโนมัติ)

---

## 💻 โครงสร้างระบบ (System Architecture)
* **Firmware:** โค้ดสำหรับ ESP32 (`codeESP32.ino`) ที่ควบคุมการอ่านค่าเซนเซอร์และสื่อสารกับ Server
* **Backend:** ระบบจัดการข้อมูลด้วย PHP
    * `api.php`: รับ-ส่งข้อมูลระหว่าง ESP32 และฐานข้อมูล
    * `db.php`: จัดการการเชื่อมต่อกับฐานข้อมูล
    * `login.php` / `index.php`: ส่วนหน้าเว็บสำหรับแสดงสถานะลานจอดรถ

---

## 🚀 ฟีเจอร์หลัก (Key Features)
* **Access Control:** ระบบอนุญาตให้เข้าลานจอดด้วยการทาบบัตร RFID
* **Automatic Detection:** ใช้เซนเซอร์อัลตราโซนิกตรวจจับระยะห่าง (กำหนดเงื่อนไขไม่เกิน 8 ซม. เพื่อความแม่นยำ)
* **Real-time Monitoring:** ข้อมูลสถานะลานจอดถูกส่งไปยัง Server และอัปเดตผ่านหน้าเว็บอัตโนมัติ
